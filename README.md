# Свояк: навык для написания пакетов

Репозиторий хранит текущую версию навыка `write-svoya-igra` для создания и редактирования русскоязычных пакетов «Своей игры».

## Структура

- `SKILL.md` — основные правила написания, оформления и проверки вопросов.
- `references/calibration.md` — калибровочные примеры и авторские правки, на которые ссылается навык.

## Что покрывает навык

- тематические пятёрки с номиналами 10–50;
- поле «Форма» как обозначение искомого, а не дополнительная подсказка;
- буквенные и структурные ограничения в начале вопроса;
- запрет повторов ответов и ключевых имён/фамилий внутри темы;
- работу с закрытыми множествами;
- узнаваемость реалий для русскоязычного игрока;
- ударения в сложных именах, терминах, названиях и ответах;
- обязательные комментарии и проверенные источники.

## Обновление

При изменении правил обновляй `SKILL.md`, а примеры и спорные случаи добавляй в `references/calibration.md`.
